# Lynko

Le lien professionnel, en un scan.

Lynko est une application de carte professionnelle numérique qui permet de créer son profil, partager ses coordonnées grâce à un QR Code et gérer son réseau professionnel.

## Objectif

Faciliter les échanges professionnels, centraliser les contacts et permettre le partage d'informations sans dépendre d'Internet.

## Fonctionnalités prévues

- Création de profil professionnel
- Carte numérique
- QR Code personnel
- Scanner QR Code
- Carnet de contacts
- Favoris
- Notes de rencontres
- Sauvegarde locale
- Fonctionnement hors ligne

## Technologies

- Flutter
- Dart
- Stockage local
